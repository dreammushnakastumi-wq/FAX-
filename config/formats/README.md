# フォーマット定義ファイル

このフォルダには、得意先ごとのフォーマット定義を保存します。

## ファイル構成

- `format_template.json`: フォーマット定義のテンプレート
- `customer_formats.json`: 実際の得意先別フォーマット定義

## フォーマット定義の追加方法

`customer_formats.json` を編集して、新しい得意先のフォーマットを追加します。

### 例

```json
{
  "得意先B": {
    "formats": [
      {
        "name": "フォーマット1",
        "date_pattern": "日付.*?(\\d{4}[年/]\\d{1,2}[月/]\\d{1,2}[日])",
        "order_number_pattern": "発注[№番号]*[：:]\\s*([^\\n]+)",
        "customer_pattern": "得意先[：:]\\s*([^\\n]+)",
        "delivery_pattern": "納品先[：:]\\s*([^\\n]+)",
        "items_pattern": "品名.*?数量.*?単価.*?金額",
        "delivery_date_pattern": "納品日[：:]\\s*(\\d{4}[年/]\\d{1,2}[月/]\\d{1,2}[日])"
      },
      {
        "name": "フォーマット2",
        "date_pattern": "注文日[：:]\\s*(\\d{4}[年/]\\d{1,2}[月/]\\d{1,2}[日])",
        ...
      }
    ]
  }
}
```

## パターンの書き方

正規表現を使用してパターンを定義します。

- `(\\d{4})`: 4桁の数字（年）
- `([^\\n]+)`: 改行以外の文字列
- `[：:]`: コロンまたは全角コロン

## 注意事項

- パターンは実際のFAX注文書の形式に合わせて調整してください
- 複数のフォーマットがある場合は、`formats` 配列に複数の定義を追加できます
- システムは最初に一致したフォーマットを使用します
